从 GCN 到 GAT：公式、直觉与代码笔记

发表于 2026-08-05 分类于 图神经网络
以公式、直觉、代码和模型对比四个角度整理 GCN 与 GAT 的核心机制。

图神经网络（GNN）需要把规则网格数据上的深度学习方法迁移到不规则的拓扑数据上。图卷积网络（GCN）是这一领域的基础，也是理解图学习中消息传递思想的一个合适起点。

GCN

下面从公式、直觉、代码和模型对比四个方面整理 Kipf 和 Welling 在 2017 年提出的经典 GCN 模型。

2. 公式所代表的几何含义 / 数学直觉

这个看似复杂的公式，其实可以用**“消息传递与特征平滑”**的直觉来拆解。我们可以将核心部分 分解为三个动作：

  • 特征变换（）：
    • 直觉： 这与普通的全连接层无异。它将节点的特征向量从当前空间投影到一个新的特征空间。此时，每个节点仅仅是“自己思考”，还没有和邻居发生联系。
  • 加上自环的邻居聚合（ ）：
    • 直觉： 如果我们将 乘以上一步的结果，几何意义是**“收集并相加”**邻居的特征。为什么邻接矩阵 要加上单位矩阵 ？因为在更新节点自身状态时，我们不仅要听取邻居的“意见”，也要保留自己原有的“记忆”。如果不加 ，节点在更新后就会丢失自身的原有特征。
  • 对称归一化（）：
    • 直觉： 如果直接把邻居特征相加，度数很大（朋友很多）的节点，其特征值会呈爆炸式增长；度数很小的节点，特征值会非常微弱，这会导致训练极不稳定。
    • 几何意义： 乘以 相当于做均值池化（Average Pooling）。但 GCN 使用了 这种对称归一化。它不仅考虑了目标节点的度（朋友多不多），还考虑了源节点的度（邻居的朋友多不多）。如果你的邻居是一个超级大 V（度数极大），他对你的影响力应该被削弱（因为他的注意力被分散了）；如果你的邻居只有你一个朋友，他对你的影响力权重就会很大。本质上，这是一个图上的低通滤波器，使得相邻节点的特征趋于一致（同质性）。

4. 和普通卷积神经网络 (CNN) 的对比

为了更好将你现有的知识迁移过来，我们通过以下表格，从几个核心维度对比传统的 2D CNN 与 GCN：

比较维度 传统 CNN (如 ResNet) 图卷积网络 GCN
处理的数据空间 欧几里得空间（Euclidean Data）。数据呈规则网格状排列，如图像的像素。 非欧几里得空间（Non-Euclidean）。数据表现为复杂的拓扑结构，节点连接不规则。
感受野与邻居 固定大小且有序。例如 3x3 的卷积核，每个像素严格有 8 个邻居，具有明确的上下左右空间顺序。 大小不定且无序（排列不变性）。一个节点可能有 1 个邻居，也可能有 1000 个邻居，且邻居之间没有空间顺序。
权重的共享方式 空间特征共享。卷积核的参数（如 3x3=9 个权重）在图像的不同局部位置滑动并共享。 变换规则共享。矩阵 在所有节点上共享，图卷积的“空间性”由固定的邻接矩阵 提供，而不是通过滑动窗口。
平移不变性 具备。图像里的猫无论在左上角还是右下角，CNN 都能识别。 不具备传统的平移不变性，但具备同构图不变性（图的节点打乱顺序重新排列，输出结果不受影响）。

理解了这四步，你就已经掌握了 GCN 的精髓。随着层数的加深，GCN 也会面临一些独有的挑战。

理解 GCN 时，一个常见难点是把矩阵形式和底层的节点交互对应起来。

其实，GCN 的巧妙之处就在于用优雅的线性代数运算，完美等价了图上的拓扑遍历操作。我们把这两个问题拆开，用最直白的方式推导一遍。

这就是 GCN 公式中看似枯燥的矩阵运算背后隐藏的图拓扑逻辑。

GAT

在理解了 GCN 通过对称归一化（）来固定分配邻居权重的机制后，图注意力网络（Graph Attention Networks, GAT）的出现就显得顺理成章了。GAT 解决的是 GCN 的一个核心痛点：GCN 认为图中节点之间的连接权重仅仅取决于它们的度数（拓扑结构），而 GAT 认为权重应该由节点自身的特征内容动态决定。

接下来仍从公式、直觉、代码和模型对比四个方面整理 Veličković 等人在 2018 年提出的经典 GAT 模型。

2. 公式所代表的几何含义 / 数学直觉

GAT 的数学公式非常直观，它本质上是一个**“相亲双向选择”**的过程：

  • 拼接与打分 ( 与 )：
    • 直觉： 在 GCN 中，张三（度数 10）传给李四（度数 5）的信息权重永远是固定的。但在 GAT 中，我们把张三的特征和李四的特征**拼接（）**在一起，这代表我们在同时审视这两个人的特质。
    • 几何意义： 权重向量 可以看作是一个超平面。它在拼接后的高维特征空间中，评估张三和李四的特征组合是否“匹配”或“重要”。如果两者的特征组合在这个超平面上的投影值很大，说明 对 很重要。
  • LeakyReLU 激活：
    • 直觉： 相比于普通的 ReLU，LeakyReLU 允许微小的负梯度通过。这意味着即使张三和李四目前看起来“非常不匹配”（得分为负），我们也不一棍子打死（置为 0），而是保留微弱的联系，让网络在反向传播时有机会修正这个看法。
  • Masked Softmax (局部归一化)：
    • 直觉： 一个人（节点 ）的注意力是有限的（总和为 1）。Softmax 就是在做注意力的分配。
    • 几何意义： 与全局 Softmax 不同，这里的求和底数仅仅是 （仅仅是节点 的真实邻居）。这被称为 Masked Attention（掩码注意力）。它强制网络只能把注意力分配给图拓扑结构中实际相连的节点，将图的结构信息（先验知识）硬编码到了注意力分配中。

4. 和普通 Attention（如 Transformer）的对比

GAT 和自然语言处理中 Transformer 所使用的自注意力机制（Self-Attention）同宗同源，但针对图数据做了极具针对性的改造。它们的对比如下：

比较维度 普通 Attention (Transformer) 图注意力网络 (GAT)
拓扑结构的假设 全连接图（Fully Connected Graph）。序列中的每个 Token 都会计算与所有其他 Token 的注意力分数。它假设没有先验的连接关系。 稀疏图（Sparse Graph）。节点 仅仅计算与图中它的邻居节点（）的注意力分数。它强制利用了图的先验拓扑结构。
计算复杂度 。因为需要计算两两之间的得分，节点数量 大时计算量很高。 **$\mathcal{O}(
位置 / 结构信息的注入 必须依赖显式的位置编码（Positional Encoding）。因为全连接图本身没有顺序或局部结构的天然概念。 不需要显式的结构编码。图的邻接矩阵（掩码操作）自然而然地将拓扑结构编码到了模型内部。
打分机制的设计 通常采用 Scaled Dot-Product Attention，通过定义三组不同的权重 （Query, Key, Value），利用点积计算相似度。 原始论文采用 Additive Attention（加性注意力）。使用同一组共享权重 ，将特征拼接后通过向量 和非线性激活函数映射为标量得分。

Transformer 里的 Attention 通过让所有数据互相计算注意力来学习潜在结构；GAT 则直接利用已有的图结构（边）作为掩码，在这个约束下计算局部注意力权重。
