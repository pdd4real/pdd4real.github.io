L1/L2 正则化、Frobenius 范数与 RegMean

L1/L2 正则化、Frobenius 范数与 RegMean

本文整理 L1、L2 正则化的基本概念，并补充 Frobenius 范数与矩阵迹的关系，以及 RegMean 正则项和传统 L2 正则化之间的区别。

不同的正则化

$$\begin{array}{l}
&\text{Def. 1: if } x=[x_1,\ldots,x_n]^\top,\
&\text{then } ||x||p=\left(\sum{i=1}^{n}|x_i|^p\right)^{\frac{1}{p}}.
\end{array}$$

  • 一般来说，supervised learning的objective function可以看作是

  • 第一项是衡量模型对第i个样本的预测值和真实标签之间的误差，也就是要求我们的模型尽量的拟合我们的训练数据。但我们不仅要保证训练误差最小，我们更希望我们的模型测试误差小，所以我们需要加上第二项，也就是对参数w的规则化函数去约束我们的模型尽量的简单。

  • 有很多种选择，一般是模型复杂度的单调递增函数，模型越复杂，规则化值就越大。比如，规则化项可以是模型参数向量的范数。

L1-Norm

L1范数和L0范数可以实现稀疏，L1因具有比L0更好的优化求解特性而被广泛应用。

  • L1范数又称稀疏规则算子（Lasso Regularizer）。任何的规则化算子，如果他在 的地方不可微，并且可以分解为一个“求和”的形式，那么这个规则化算子就可以实现稀疏。
  • feature selection：将一些参数置0相当于在去掉没用的特征。
  • interpretability：可以解释目标和最后学习到的非0特征的相关性。
为什么L1范数可以实现稀疏化？


  • 目标loss函数通常是一圈圈椭圆等高线（下图以抛物面为例，等高线是一圈圈的同心圆），优化过程相当于椭圆等高线不断扩张直到第一次触碰到L1-Ball
  • 由于 L1-ball 的几何形状是一个带有尖锐顶点的菱形，并且这些顶点突出在坐标轴上。
  • 当外围的椭圆等高线向内收缩并与这个菱形相切时，由于菱形的“角”是最往外凸出的部分，椭圆有极高的概率直接与这些角相交，而不是与平直的边相切。
  • 一旦相切点位于“角”上（例如交点在 ），此时 就严格等于 0。这就产生了稀疏解。

L2-Norm

又称岭回归（Ridge Regression）或者Weight Decay。主要用于改善过拟合。

直观上看，L2-Norm是让每个参数都尽量小，防止某个feature对最终结果影响过大。

RegMean 损失函数中的正则化项本质上是对权重偏离度的惩罚，但它与传统的 正则化在惩罚力度的分配机制上有根本区别。

一句话概括：标准 正则化对所有权重的偏离进行无差别的均匀惩罚（各向同性），而 RegMean 的正则化项是一种数据驱动的、自适应的惩罚（各向异性）。

可以从数学公式和直觉两个角度比较二者。

一、 数学公式对比

如果我们要用传统的 正则化来约束融合权重 靠近候选模型权重 ，其迹形式（Trace form）的数学表达式通常是这样的：

$$\mathcal{L}{L2} = \lambda \sum{i=1}^{K} tr[(W_{M}^{(l)} - W_{i}^{(l)})^{\top}I(W_{M}^{(l)} - W_{i}^{(l)})]$$

其中， 是单位矩阵， 是统一的标量惩罚系数。

而 RegMean 的正则化项为：

$$\mathcal{L}{Reg} = \sum{i=1}^{K} tr[(W_{M}^{(l)} - W_{i}^{(l)})^{\top}\Lambda_{i}^{(l)}(W_{M}^{(l)} - W_{i}^{(l)})]$$

二、 核心区别详解

1. 惩罚项的“各向同性” vs “各向异性”

  • 正则化：因为使用的是单位矩阵 （或统一常数），所以它对权重矩阵中每一个元素的改变都施加完全相同的惩罚。

RegMean 正则化：使用的是对角矩阵 ，这意味着它对 中不同行的权重施加了不同量级的惩罚 。

2. 数据依赖性 (Data-Dependence)

  • 正则化：惩罚力度 是一个固定的超参数，与输入数据完全无关。

RegMean 正则化：惩罚矩阵 直接由该层输入特征的内积矩阵 决定 。矩阵的对角线元素 代表了各个输入特征维度在候选模型 的数据集上的激活强度（或方差） 。

3. 物理直觉与目的

  • 特征重要性感知的约束：如果某个维度的特征在候选模型 中经常被激活且数值很大（对应对角线元素值很大），RegMean 会认为与该特征相乘的权重非常重要，因此会对其施加强烈的正则化约束，迫使融合后的权重在这个方向上极度贴合原模型 。

  • 反之，如果某个特征维度处于休眠状态（数值趋近于 0），则允许融合权重在该方向上有更大的自由度。

  • 增强稳定性：论文明确指出，RegMean 通过减小内积矩阵的非对角线元素（即提取对角线部分 ）来增强融合过程中的稳定性 。

总结

可以将 正则化看作是“一刀切”的橡皮筋，无论哪个方向拉伸，回弹力都一样；而 RegMean 的正则化项是一张“智能弹簧网”，它的各个节点的弹力大小是由候选模型的训练数据特征决定的，重要特征对应的弹力极强，次要特征对应的弹力较弱 。
